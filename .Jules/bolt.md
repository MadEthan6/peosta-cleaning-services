## 2026-09-30 - Prevent Component Recreation inside Render Body\n**Learning:** Defining a functional component (like `JobCard`) inside another functional component's render body (like `ClientHistory`) destroys performance. React sees a completely new component reference on every parent render, forcing it to fully unmount the old DOM nodes and remount new ones, bypassing any potential reconciliation or memoization.\n**Action:** Always extract child components outside the parent component's body. Explicitly pass required data as props (avoiding closures), and wrap the extracted component in `React.memo` to leverage shallow prop comparison and prevent unnecessary re-renders.
