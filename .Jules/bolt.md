
## 2023-10-24 - React List Component Memoization and State Extraction
**Learning:** Defining a functional component (like `JobCard`) inside a parent component (like `ClientHistory`) triggers a full unmount and remount of all child list items on every parent render, completely negating React's reconciliation. Furthermore, multiple sequential `.filter()` operations on arrays inside the render function create redundant array iterations and new object references that trigger downstream effects, even for unrelated state changes (like item selection).
**Action:** Always extract list item components outside the parent and wrap them in `React.memo`. When dealing with list items that have a "selected" state, pass derived primitive boolean props (e.g., `isSelected={selected?.id === job.id}`) instead of checking state inside the child. Combine multiple array derivations (like filtering upcoming/past lists) into a single loop wrapped in `useMemo` to prevent expensive redundant recalculations.
