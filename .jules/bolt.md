## 2026-10-26 - Component extraction and React.memo\n**Learning:** Defining functional components inside other functional components causes the inner component to unmount and remount on every parent render, leading to significant performance degradation, especially in lists. Extracting it outside the parent and wrapping it in `React.memo` prevents this.\n**Action:** Always define components at the module level. If the component needs parent state, pass derived primitive props (like a boolean `isSelected`) instead of relying on closure variables, which maximizes the benefits of `React.memo`.
