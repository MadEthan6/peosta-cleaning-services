## 2024-05-24 - Avoiding nested components and leveraging `React.memo` for list performance
**Learning:** Defining a functional component inside another functional component triggers full unmounting and remounting on every parent render, destroying component state and wasting performance. Furthermore, passing whole state variables (like `selected`) down to list components causes all list items to re-render when selection changes.
**Action:** Extract nested definitions outside the parent component. Explicitly pass primitive boolean props (e.g., `isSelected={selected?.id === job.id}`) instead of a global selection ID to all children, and wrap the extracted component in `React.memo` to maximize memoization benefits and ensure only the newly and previously selected items re-render.
