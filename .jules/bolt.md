## 2024-05-18 - Prevent Unnecessary Re-renders with Extracted Components and Derived Primitive Props
**Learning:** Defining a functional component (like `JobCard`) inside its parent (`ClientHistory`) forces React to re-create the component definition on every parent render, defeating memoization and causing all list items to unmount and remount. Furthermore, passing an ID prop and computing `selected?.id === job.id` inside the item means the item re-renders whenever `selected` changes, even if it wasn't selected or deselected.
**Action:** Always extract child components outside the parent component body. When optimizing lists with `React.memo`, compute the derived selection state (`isSelected={selected?.id === job.id}`) in the parent and pass it as a primitive boolean prop, so only the two items that actually change state will re-render.
