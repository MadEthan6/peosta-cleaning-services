## 2024-05-18 - Extracted Inner Components for Performance
**Learning:** Defining a functional component (like `JobCard`) directly inside the render body of a parent functional component (like `ClientHistory`) is a significant performance anti-pattern in React. It causes the inner component to be fully unmounted and remounted on every parent render, defeating React's reconciliation algorithm and destroying any internal state or DOM focus.
**Action:** Always extract inner component definitions outside of their parent component. Pass any required context (which was previously captured via closure) explicitly as props, and wrap the extracted component in `React.memo` if it receives stable primitive props (like a derived `isSelected` boolean) to prevent unnecessary re-renders.
