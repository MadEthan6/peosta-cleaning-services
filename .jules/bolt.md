## 2024-05-18 - Prevent Unnecessary Re-mounts of Nested Functional Components\n**Learning:** Defining a functional React component (like `JobCard`) inside another functional component (`ClientHistory`) forces React to see a new component reference on every render, triggering full unmounting and remounting of all instances of the child component whenever the parent updates.\n**Action:** Always extract functional component definitions to the top level outside of parent components. explicitly pass required data via props instead of relying on closures, and wrap them in `React.memo` to allow React to efficiently skip re-rendering instances whose props have not changed.
