## 2024-05-23 - Memoizing Derived Arrays and Functional Components in React Lists
**Learning:** In the Peosta Cleaning app, list components (like `ClientHistory`) frequently derive sub-lists (like `upcoming` and `past`) and render child functional components defined inside the parent. Defining functional components like `JobCard` inside the parent causes full unmounting and remounting on every render, severely degrading performance. Additionally, running multiple `.filter()` operations on every render for state derivations is inefficient.
**Action:** Always extract functional component definitions outside of their parent component, pass necessary data explicitly via props (avoiding closures), and wrap them in `React.memo`. When processing arrays derived from state, combine operations (like chained `.filter()` calls) into a single loop and wrap the computation in `useMemo` to prevent redundant recalculations during unrelated state updates (like merely clicking to select an item). Pass derived boolean props to children instead of global selection IDs to maximize memoization.
