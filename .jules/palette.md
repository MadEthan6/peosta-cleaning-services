## 2024-05-24 - Interactive Elements & Icon Buttons Accessibility
**Learning:** In JobChecklist, custom interactive elements (like the task toggle div) were missing keyboard accessibility, and icon-only buttons lacked aria-labels, making them inaccessible to screen readers and keyboard users.
**Action:** When converting non-interactive elements (like a `div`) into interactive components, always ensure keyboard accessibility by adding `role="button"`, `tabIndex={0}`, an appropriate `aria-label`, and an `onKeyDown` handler for both 'Enter' and ' ' (Space) keys. For icon-only buttons, standard UX/a11y practice is to include both an `aria-label` for screen readers and a dynamic `title` attribute for hover tooltips. Also, add `aria-hidden="true"` to decorative icons inside the button.
