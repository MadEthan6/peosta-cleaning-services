## 2024-05-24 - Do Not Expose Stripe Secret Key in Frontend Settings
**Vulnerability:** Stripe secret key was being fetched via `supabase.from('business_settings').select('*')` and stored in frontend component state (`OwnerSettings.jsx`), exposing it to anyone loading the dashboard.
**Learning:** Even internal admin dashboards running on the client-side expose their memory and network requests to the browser. Admin configurations containing backend secrets (like `stripe_secret_key`) should never be fetched to or managed from frontend state.
**Prevention:** Avoid `select('*')` on configuration tables. Explicitly select only public/publishable keys for frontend usage. Manage backend secrets purely through secure backend operations/edge functions, and never bind them to frontend state variables.
